# BlindStudy — AI 맞춤형 내신 학습 플랫폼

교과서 PDF와 시험 범위를 등록하면 AI가 해당 범위만을 근거로 핵심 개념 암기장, 예상 문제, 고난도 서술형 첨삭, 실전 내신 시험지, 취약 개념 맞춤형 변형 재시험까지 제공하는 웹 애플리케이션입니다.

## 주요 기능
- **원페이지 PDF · 범위 빠른 설정**: PDF 업로드·드래그 앤 드롭, 페이지 범위 및 학습 모드 즉시 선택, 스캔 페이지 병렬 AI OCR, 인쇄 쪽수 매핑, IndexedDB 로컬 영구 저장
- **교과서 맞춤 배경 테마**: 선택한 교과서·과목(한국사, 국어, 영어, 수학, 생명과학, 화학, 물리/통합과학, 사회 등)에 맞춰 화면 배경과 테마가 자동 전환
- **개인정보 자동 보호**: 모든 PDF와 학습 기록은 사용자 브라우저(IndexedDB)에만 저장되며, AI 요청 시 전화번호·이메일·학번 등 민감 정보 자동 마스킹 적용
- **고속 병렬 분석 & 문항 생성**: 긴 범위의 텍스트와 대량 문항 요청을 소형 마이크로 배치로 분할해 병렬 처리
- **MODE A (AI 자동 암기장)**: 쉬움/보통/어려움 빈칸 카드, 클릭 정답 확인, 알고 있음/모르겠음 복습 필터, 원본 페이지 확인
- **MODE B (AI 예상 문제)**: 5~30문항, 3단계 난이도, 6가지 문제 유형(5지선다/OX/단답형/서술형/자료해석/복합추론), **1차 오답 시 정답 비공개 → 2차 시도 시 정답 공개**, 교과서 외 지식·Google 검색 기반 AI 오답 원인 분석
- **MODE C (AI 고난도 서술형)**: **채점 전 힌트·기준표 비노출**, AI 채점 후 세부 루브릭 평가 및 개선 방향 제공, 1차 미달 시 모범 답안 비공개 후 2차 시도 시 공개
- **MODE D (AI 실전 내신 시험지)**: 타이머·시험지 UI·제출 후 자동/AI 일괄 채점·오답 원인 AI 조회·이전 시험 비교·시험지 및 정답/해설지 인쇄
- **취약점 분석 & 맞춤형 재시험**: 반복 오답 패턴 기반 취약 개념 진단, 난이도 자동 조정, 기존 문제를 반복하지 않는 유형 변환 재시험

## 기술 스택
- **Frontend**: React 19, TypeScript, Tailwind CSS v4, PDF.js (`pdfjs-dist`), IndexedDB (`idb`), Recharts, Lucide React
- **Backend**: Node.js (v22+ 권장), Express, `@google/genai`

## 로컬 실행 및 배포 방법

1. **의존성 설치**
   ```bash
   npm install
   ```

2. **환경 변수 설정**
   `.env.example`을 참고해 프로젝트 루트에 `.env` 파일을 생성하고 Gemini API 키를 입력합니다.
   ```env
   GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
   ```
   *(`.env` 파일은 `.gitignore`에 포함되어 있어 GitHub에 올라가지 않습니다.)*

3. **개발 서버 실행**
   ```bash
   npm run dev
   ```
   브라우저에서 `http://localhost:3000`으로 접속합니다.

4. **프로덕션 빌드 및 실행**
   ```bash
   npm run build
   NODE_ENV=production npm start
   ```
